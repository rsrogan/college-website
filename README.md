# 🎓 College Website Project

A responsive and informative college website built using **HTML**, **CSS**, and the **Bootstrap** framework. This project showcases essential features for academic institutions, including admission forms, department pages, event galleries, and student dashboards.

## 🌟 Features

- **🏠 Home Page**: Clean layout with quick access to key sections.
- **📝 Admission Form**: Interactive form for student applications.
- **📚 Department Pages**: UG and PG program details with dedicated sections.
- **🖼️ Event Gallery**: Visual showcase of campus events.
- **📊 Research & Sports Pages**: Highlights academic research and extracurricular activities.
- **👥 Web Team Page**: Introduces the development and support team.
- **🔐 Login & Signup Pages**: Basic authentication interface for students and staff.
- **📱 Responsive Design**: Optimized for all screen sizes using Bootstrap.

## 🧰 Tech Stack

| Technology | Purpose                     |
|------------|-----------------------------|
| HTML       | Structure of web pages      |
| CSS        | Styling and layout          |
| Bootstrap  | Responsive design framework |

## 🚀 Getting Started

To run the project locally:

```bash
git clone https://github.com/rsrogan/college-website.git
cd college-website
open index.html
```

Or simply open `index.html` in your browser.

## 📁 File Structure

- `index.html` – Homepage
- `admission.html` – Admission form
- `ug.html`, `pg.html` – Program pages
- `gallery.html` – Event gallery
- `login.html`, `signup.html` – Authentication pages
- `dashboard.html` – Student dashboard
- `research.html`, `sport.html` – Additional sections
- `webteam.html` – Team introduction
- `assets/` – Images and media
- `style.css`, `about.css`, `galery.css`, `login.css` – Custom styles
